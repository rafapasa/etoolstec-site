# eTools Tecnologia — Site

Site institucional em Flutter Web.

- Domínio: https://www.etoolstec.com.br
- Backend previsto: https://mcp-server.etoolstec.com.br/api/v1
- Endpoints ainda não publicados: veja `lib/core/constants/api_constants.dart`

## Executar

```bash

# ou
flutter build web --release
```
